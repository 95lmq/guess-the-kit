Guess the Kit!

FAQ & Information

What is this game?
This is a military kit recognition game, designed to improve your recognition skills. It uses real life images from Ukraine to help train your skills on representative data
What are the game settings?
The settings let you choose how long the timer is, the number of images in a 'round', and Typing or Flashcard mode. In typing mode, there is a user input for you to put in your guess
Can I get in touch with the developer?
This game was made by 95lmq (GitHub username). If you want to get in touch, please go to the GitHub repo here (https://github.com/95lmq/guess-the-kit) and use the Discussions tab to send a message
Can I access the code?
It's all in a GitHub repo here (https://github.com/95lmq/guess-the-kit)
Where are the images from?
The images are from the Oryx dataset (https://www.oryxspioenkop.com), which is a Ukraine war loss tracker. It tracks both Russian and Ukrainian losses. Most of the images in that database are from Twitter – these aren't included in the game. Some entries were also filtered out for various reasons including lack of data, and having data that is tricky to sort
