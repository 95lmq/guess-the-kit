# guess-the-kit
Military kit recognition game.
Access the game page at [95lmq.github.io](https://95lmq.github.io/guess-the-kit/)

This is a recognition game for military hardware, using real life images taken in Ukraine. The data is from Oryx - a loss tracker for hardware in Ukraine. The date range of the data is roughly Feb 2022 - July 2025.
There are two game modes - one is a flashcard style "Reveal" button setup. The other lets you type in a guess and the system will do its best to evaluate your answer.
